# Kantin Multi-Tenant

Project praktikum Laravel 13 untuk pengembangan sistem kantin multi-tenant.

## Teknologi

- Laravel 13
- PHP 8.4
- Livewire 4
- MariaDB
- Redis
- Laravel Reverb
- Vite
- PHPUnit

## Requirements

- PHP 8.3 atau lebih baru
- Composer
- Node.js dan NPM
- Git
- MariaDB
- Redis

Clone repository kemudian masuk ke folder project:

```bash
cd kantin-multi-tenant
